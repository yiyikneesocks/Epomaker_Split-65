## v5.1 — 链路诊断状态机版（A 深睡 / B 常醒）

在 v5 全部功能基础上，按实测修正的硬件模型（**单条灯链由主半驱动、右半纯靠链路 5V 供电**）重做诊断灯：

- 灯位：`6/7` → **左 Ctrl(LED4) / 右 Ctrl(LED64)**，与 13 键红灯排、Caps/Win 灯零交集
- **正常 = 全灭**（撤销 v5 的绿色常亮）
- 进入异常（断线/数据坏=红；有线且右半供电断=黄）：**先闪 3 下 → 常亮**；开机即异常直接常亮；红↔黄切换按新色重闪
- 恢复正常：**绿闪 3 下 → 灭**
- 黄闪仅主半判定显示（从半充电读数缺电时不可信）
- 省电：所有提示灯（诊断、F 模式红灯排、Caps/Win、极限白闪）亮度统一改为 **灯效亮度 +1 档、封顶 150**
- A/B 诊断行为一致（右半常年在线，无"睡着误报"问题），两版差异仅剩无线深睡开关
